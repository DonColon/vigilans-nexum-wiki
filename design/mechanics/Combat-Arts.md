# Combat Arts

> **Verwandte Dateien:** [Abilities](Abilities.md) · [Magic System](Magic-System.md) · [Unit Classes](../catalog/Unit-Classes.md)

---

## Übersicht

Combat Arts sind aktive Kampffähigkeiten mit Fokus auf die **Player Phase**. Sie werden vom Spieler gezielt und taktisch eingesetzt — im Gegensatz zu Abilities, die automatisch in der Enemy Phase triggern.

|           | Combat Arts                                   |
| ------ | ------------------------ |
| Phase     | Player Phase                                  |
| Auslösung | Spieler wählt aktiv                           |
| Ressource | Kostet MP                                     |
| Element   | Jeder Combat Art ist einem Element zugewiesen |

---

## Voraussetzungen

Combat Arts sind klassengebundene Fähigkeiten. Sie können nur eingesetzt werden, wenn sie zuvor erlernt wurden, und erfordern ausreichend MP.

| Bedingung | Regel |
| ------ | ----- |
| Erlernen | Klassenaufstieg oder Level-Up in der jeweiligen Klasse |
| MP-Kosten | Jede Art kostet MP — Menge variiert je nach Art |
| Permanenz | Einmal gelernte Arts bleiben auch nach einer Beförderung erhalten |

---

## Kernregeln

### Combat Arts & das Elementarsystem

Combat Arts sind die einzige Möglichkeit für **Nicht-Magier**, Elemente zu applizieren und Elementarreaktionen auszulösen.

| Aktion                                  | Ergebnis                                |
| --------------------- | --------------------- |
| Combat Art auf Gegner ohne Element      | Element wird appliziert                 |
| Combat Art auf Gegner mit Element       | Elementarreaktion wird ausgelöst        |
| Normaler Angriff auf Gegner mit Element | Schaden — Element **bleibt** auf Gegner |

Das bedeutet: Nicht-Magier müssen MP investieren, um überhaupt am Elementarsystem teilzunehmen. Combat Arts sind dadurch nicht nur Schadensoptionen, sondern taktische Reaktionsauslöser.

### MP-Kosten & Regeneration

Nicht-Magier bauen MP durch **normale Angriffe** auf und geben es durch Combat Arts aus.

| Mag-Wert | MP pro normalem Angriff |
| ----- | -------------- |
| 0–5      | +1 MP                   |
| 6–12     | +2 MP                   |
| 13+      | +3 MP                   |

Der Mag-Stat ist damit auch für Nicht-Magier relevant — ein höherer Mag-Wert bedeutet schnelleres MP-Aufbauen und häufigere Arts.

## Erwerb / Zugang

| Quelle          | Beschreibung                                       |
| --------- | -------------------------- |
| Klassenaufstieg | Klassenspezifische Combat Arts automatisch erlernt |
| Level-Up        | Gelegentlich neue Arts innerhalb der Klasse        |

Combat Arts sind **klassengebunden** — im Gegensatz zu Abilities gibt es keine Scroll-Arts. Alle erlernten Arts bleiben jedoch **permanent** erhalten, auch nach einer Beförderung in die nächste Klassenstufe.

---

## Strategische Tiefe

Combat Arts sind das Bindeglied zwischen physischen Einheiten und dem Elementarsystem. Ihre strategische Bedeutung liegt auf mehreren Ebenen:

- **Elementarer Zugang:** Ohne Combat Arts können Nicht-Magier keine Elemente applizieren und damit keine Reaktionen auslösen — sie sind vom stärksten Teil des Schadensystems ausgeschlossen.
- **MP-Haushalt:** Da MP durch normale Angriffe aufgebaut wird, entsteht ein Rhythmus: angreifen, aufbauen, im richtigen Moment die Art einsetzen. Zu frühes Einsetzen verschwendet Potenzial.
- **Kettenangriff-Vorbereitung:** Im Boss-Kampf entscheidet die Reihenfolge der Arts über die Qualität der Elementarreaktionen. Wer welche Art in welcher Runde einsetzt, ist die taktische Kernfrage.
- **Klassenidentität:** Da Arts klassengebunden sind, legt jede Beförderung die taktische Rolle einer Einheit dauerhaft fest — Beförderungen sind einmalig und nicht umkehrbar, es gibt keinen Klassenwechsel. Welche Arts eine Einheit je beherrschen wird, entscheidet sich an den vier Verzweigungen ihres Klassenbaums.

## Interaktion mit anderen Mechaniken

### Combat Arts im Kettenangriff

Im Kettenangriff gegen Bosse können alle drei beteiligten Units ihre Combat Arts einsetzen. Das ermöglicht 3-Element-Reaktionen innerhalb eines einzigen Kettenangriffs — die mächtigste Anwendung des Systems.

Für Details zum Kettenangriff siehe: [Chain Attack](Chain-Attack.md)

| Mechanik | Interaktion |
| ----- | -------- |
| Kettenangriff | Arts aller drei Einheiten können zur 3-Element-Reaktion kombiniert werden |
| Abilities | Ergänzen sich: Arts für Player Phase, Abilities für Enemy Phase |
| Magic System | Arts sind der einzige Weg für Nicht-Magier, am Elementarsystem teilzunehmen |
