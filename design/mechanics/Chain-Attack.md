# Kettenangriff

> **Verwandte Dateien:** [Magic System](Magic-System.md) · [Combat Arts](Combat-Arts.md) · [Unit Classes](../catalog/Unit-Classes.md)

---

## Übersicht

Der Kettenangriff ist ein mächtiger koordinierter Angriff von drei Units gegen einen einzelnen Gegner. Er ist ausschließlich gegen **Spezielle Enemy Units** verfügbar und muss durch das Brechen eines Schutzschildes erst freigeschaltet werden.

|              | Kettenangriff                                           |
| ------ | ---------------------------- |
| Phase        | Player Phase                                            |
| Auslösung    | Manuell — nach Schildbruch durch drei positionierte Units |
| Ressource    | MP (für Combat Arts innerhalb des Angriffs)             |
| Besonderheit | Exklusiv gegen Spezielle Enemy Units / Bosse            |

---

## Voraussetzungen

| Bedingung    | Regel                                                 |
| ------ | ----------------------------- |
| Gegnertyp    | Nur gegen Spezielle Enemy Units (Bosse, Elite-Gegner) |
| Schutzschild | Muss erst gebrochen werden                            |
| Anzahl Units | Genau 3 Units müssen in Position stehen               |
| Formation    | Dreieck um den Gegner                                 |

---

## Kernregeln

### Schutzschild brechen

Spezielle Enemy Units besitzen eine Schutzleiste die vor dem Kettenangriff gebrochen werden muss.

| Aktion                | Effekt auf Schutzleiste              |
| ------------ | ------------------ |
| Elementarreaktionen   | Hohe Reduktion — effektivste Methode |
| Critical Hits         | Mittlere Reduktion                   |
| Bestimmte Combat Arts | Mittlere Reduktion                   |
| Normale Angriffe      | Geringe oder keine Reduktion         |

Das Elementarsystem aktiv zu nutzen ist damit nicht optional — es ist der schnellste Weg in die Kettenangriff-Phase.

### Schildphasen

Bosse haben **2–3 Schildphasen**. Jede Phase ist schwerer zu brechen als die vorherige.

| Phase                       | Schwierigkeit | Boss-Reaktion                      |
| --------------- | ------- | ------------------- |
| Phase 1                     | Normal        | Neue Angriffsmuster                |
| Phase 2                     | Erhöht        | Stärkere Moves, neues Element      |
| Phase 3 *(falls vorhanden)* | Hoch          | Dramatischer Abschluss des Kampfes |

Nach jeder gebrochenen Phase verändert der Boss sein Verhalten — neue Angriffsmuster, stärkere Moves, oder ein neues Element das er appliziert. Bosse werden mit jeder Phase sichtbar geschwächt, was den Story-Moment am Ende verstärkt.

### Positionierung

Die Reichweite der beteiligten Units bestimmt die Formation:

| Range der Units | Positionierungsregel                                |
| --------- | --------------------------- |
| Range 1         | Alle drei müssen direkt an den Gegner angrenzen     |
| Range 2+        | Units können mit Abstand im Dreieck formiert werden |
| Gemischte Range | Die niedrigste Range aller beteiligten Units gilt   |

### Ablauf

1. Schutzschild der Schildphase brechen
2. Drei Units in Dreiecksformation bringen
3. Kettenangriff starten
4. Jede Unit greift nacheinander an — mit vollem Zugang zu normalen Angriffen, Spells und Combat Arts
5. Elemente bauen sich über alle drei Angriffe auf

### Elementarer Aufbau

Die Reihenfolge der Angriffe ist eine eigene taktische Entscheidung. Durch geschickte Planung ist eine **3-Element-Reaktion** innerhalb eines einzigen Kettenangriffs möglich.

| Angriff | Aktion                  | Ergebnis                          |
| ---- | -------------- | ------------------ |
| Unit 1  | Pyro-Spell / Pyro-Art   | Pyro appliziert                   |
| Unit 2  | Hydro-Spell / Hydro-Art | 2-Element-Reaktion (Verdampfen)   |
| Unit 3  | Aero-Spell / Aero-Art   | 3-Element-Reaktion (Feuersbrunst) |

Für alle möglichen 3-Element-Reaktionen siehe: [Magic System — 3-Element-Reaktionen](Magic-System.md#3-element-reaktionen)

## Erwerb / Zugang

Der Kettenangriff ist kein erlernbares Feature — er steht allen Einheiten universal zur Verfügung, sobald die Voraussetzungen auf dem Schlachtfeld erfüllt sind.

| Quelle | Beschreibung | Verfügbarkeit |
| --- | ------ | ------- |
| Universal | Steht allen drei Einheiten in Formation zur Verfügung | Sobald Schutzschild gebrochen und Formation steht |
| Schildbruch | Voraussetzung: Schutzleiste muss auf 0 reduziert werden | Nur gegen Spezielle Enemy Units |

---

## Strategische Tiefe

Der Kettenangriff belohnt mehrere Ebenen von Vorbereitung:

**Vor dem Kampf:** Welche drei Units bringt man in Position? Welche Elemente decken sie ab?

**Während des Kampfes:** Schutzschild aktiv durch Elementarreaktionen brechen — nicht durch bloßes Draufhauen.

**Im Kettenangriff selbst:** Reihenfolge der Angriffe planen um maximale Reaktionen auszulösen. MP-Haushalt beachten — wer hat noch genug für eine Combat Art?
